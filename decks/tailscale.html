Control plane, data plane.

    ┌─────────────────────────────┐
    │     coordination server     │
    │   keys · policy · netmap    │
    └────▲───────────────────▲────┘
         │                   │
     ┌───┴────┐         ┌────┴───┐
     │ laptop │◄═══════►│  box   │
     └────────┘         └────────┘
          # WireGuard tunnel
# control plane
Exchanges public keys and policy. Carries virtually no traffic.
# data plane
A WireGuard mesh. The private key never leaves its node.

# first relayed, then upgraded to direct
# the order
1 DERP relay  # at first
2 direct UDP   # NAT traversal
3 peer relay   # if (2) fails
4 DERP again   # if (3) fails
# same security
All end-to-end encrypted. Only performance differs.
~/ts $ cat policy.hujson

Grants, not ACLs.

{
  "tagOwners": {
    "tag:server": ["group:platform"]
  },
  "grants": [{
    "src": ["group:dev"],
    "dst": ["tag:server"],
    "ip":  ["tcp:22", "tcp:443"]
  }]
}
# tags
Servers log in as a tag, not as a person. tagOwners says who may apply it.
# ACLs?
Still work, but get no new features. Prefer grants.
~ $ tailscale up --ssh

SSH without keys.

# on the server
$ tailscale up --ssh

# in the policy
"ssh": [{
  "action": "check",
  "src":   ["autogroup:member"],
  "dst":   ["tag:server"],
  "users": ["root"]
}]
# how
Tailscale takes over port 22 for tailnet traffic. Node keys authenticate, WireGuard encrypts.
# check mode
Re-authenticate for risky logins (like root), then access for 12 hours (or a set period).
~/app $ tailscale serve 3000

Serve. Funnel. Embed.

# share a local server
$ tailscale serve  3000  # tailnet
$ tailscale funnel 3000  # internet
  • Funnel: ports 443, 8443, 10000
  • TLS only, capped bandwidth
  • Needs HTTPS + funnel attribute
# tsnet · embed a node in Go
s := &tsnet.Server{
  Hostname: "my-service",
}
defer s.Close()
ln, _ := s.Listen("tcp", ":80")
http.Serve(ln, handler)
A plain net.Listener, reachable only over the tailnet.
~/infra $ tailscale up --advertise-routes=10.0.0.0/24

Reach the rest.

[0] subnet router
A gateway.
Advertises a CIDR so devices without Tailscale become reachable.
[1] exit node
A way out.
Sends a device's internet traffic through one node: fixed IP or region.
[2] app connector
SaaS access.
Identity-aware access to public SaaS apps, with central policy.

Alternatives and limits.

# headscale
  • Open-source, self-hosted control server
  • ACLs, grants, SSH, OIDC, embedded DERP
  • Tags, routes, MagicDNS
  • BSD-3-Clause license
# its limits
  • One tailnet only
  • "Not enterprise software"
  • Docker not officially supported
  • Not associated with Tailscale Inc.
# trade-off: keys and policy live on a server you don't run
