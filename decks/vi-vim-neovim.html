Bonus: vis.

vi ✕ sam ──▶ minus the legacy

# origin
Marc André Tanner, 2014. Takes vi's modes and the structural regular expressions of sam, Rob Pike's editor (Plan 9).
# the promise
Not a Vim clone. A small editor, in C99, scriptable in Lua, that opens huge files without blinking.
~/bonus $ vis --help | grep -i structural

Selections, not lines.

# structural regular expressions
:x/foo/             # one selection per "foo"
:x/foo/ c/bar/      # … then replace them
:x/\w+/ g/^[A-Z]/   # capitalized words
:, x/ +$/ d         # trailing spaces, everywhere
:x/^#.*/ |tr a-z A-Z # pipe to Unix
# x extract · y between · g/v filter · c i a d act
# native multi-cursor
Each selection is a cursor. Type once, apply everywhere.
# vs vim
:s thinks in lines. vis thinks in chunks of text.
~/bonus $ ./review vis --honest

A serious contender?

# pros
  • vi muscle memory still applies
  • Structural regex + multiple selections
  • Lua, with LPeg-based highlighting
  • Fast, huge files, Unicode
  • Small C codebase, readable in a weekend
# cons
  • No vimscript, no Vim plugins
  • Small ecosystem, no native LSP
  • Rare releases (0.9 in 2024)
  • No tabs, diff, GUI or spell check, by design
# replaces vi, no regrets · replaces vim for terminal + pipes people · neovim keeps the IDE edge
